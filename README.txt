== Description ==
WordPress appointment booking plugin, developed by AZ IT. This plugin allows users to book time slots for services directly on the website.
== Installation ==
1. Download the plugin ZIP file.
2. Go to WordPress admin, then go to “Extensions > Add”.
3. Click "Upload Extension" and select the downloaded ZIP file.
4. Click "Install Now", then activate the plugin.
5. To display the appointment form, you must add the shortcode to the WordPress page [sc-formrdvpress]
